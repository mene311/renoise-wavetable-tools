2. Options

Frames per instrument is capped at 12 because Renoise allows twelve voices per note column. Cycle length sets both the register and how much high end a frame can hold: 169 samples sits at C-4 with 84 harmonics, 1070 at 41 Hz with 535.

What you get

A gate-scan wavetable instrument: one sample slot per frame, a gate LFO per frame whose triangle envelopes add up to 1.0, and macro 1 named WT Position walking the gate positions. Drop the .xrni into ~/.local/share/Renoise/User Library/Instruments/ (or the equivalent on your platform), load it, hold a note and turn macro 1.

The converter runs entirely in this page: files are read with the File API and the .xrni is assembled here, so nothing leaves your machine.
